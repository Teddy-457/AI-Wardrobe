# AI-Wardrobe

Проблем: Изборът на подходящо облекло изисква съобразяване с метеорологичните условия, повода и естетическата съвместимост на отделните дрехи. Често хората не използват пълноценно наличния си гардероб и губят време в избора на комбинации.

Потребители: Хора, които искат да организират дигитално гардероба си и да получават персонализирани предложения за облекло. Основен сценарий: Потребителят качва снимка на нова дреха → мултимодален LLM разпознава категорията, цветовете, стила и други характеристики → информацията се структурира във валиден JSON и се записва в локална база данни. При планиране на излизане потребителят избира местоположение, дата, час, повод и стил → приложението извлича прогнозата за времето чрез Weather API и информацията за наличните дрехи от базата данни → алгоритъм генерира и оценява възможните комбинации според температурните условия, цветовата хармония, повода и стила → LLM анализира най-подходящите комбинации и генерира обяснения.

Резултат: Потребителят получава няколко персонализирани предложения, визуализирани със снимки на реалните дрехи от неговия гардероб, придружени от описание и обосновка за избора.
